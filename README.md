# Smart-Household-Water-Management

## Project Overview
This project uses Machine Learning to estimate daily household water consumption based on household characteristics.

## Objectives
- Estimate household water consumption.
- Apply machine learning algorithms for water demand estimation.
- Provide useful information about household water usage.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML and CSS

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Application
A Flask-based web application that allows users to estimate household water consumption.

## How to Run

1. Clone or download this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the Flask application:

   `python app.py`

4. Open the local application URL in your browser.
